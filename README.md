# Active Directory Helpdesk Lab

A hands-on IT Helpdesk lab demonstrating the deployment,
configuration, and use of osTicket as a ticketing system.

## Overview
This project is a hands-on Active Directory Helpdesk Lab built in Microsoft Azure. It simulates a small Windows-based IT environment using a Windows Server 2022 Domain Controller (DC-1) and a domain-joined Windows client (Client-1).

The lab is divided into three sections:

## 01 — Setup and Configuration
Build and configure the Azure environment, Active Directory domain, DNS, users, groups, Organizational Units, Group Policy, and domain-joined client.

## 02 — Password Reset
Simulate a Tier 1 Helpdesk request where a user has forgotten their password. Investigate the account, reset the password, and verify successful login.

## 03 — Account Lockout
Simulate a locked Active Directory account. Investigate the account status, unlock the account, and verify that the user can successfully sign in.

## Skills Demonstrated
- Microsoft Azure
- Windows Server 2022
- Active Directory
- DNS
- Group Policy
- User and group management
- Domain joining
- Password resets
- Account lockout troubleshooting
- Tier 1 Helpdesk troubleshooting and documentation
